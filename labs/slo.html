THINGS THIS MODEL DOES NOT SAY

honest edges

Availability is not one number. A request-based SLI treats one failed health check the same as one failed checkout. Weight by user journey, or you will optimise the wrong path.

Burn rate assumes a steady rate. Real incidents are spiky — which is exactly why the policy uses several windows rather than one average.

A budget nobody enforces is decoration. If exhausting it does not stop feature releases, it is a dashboard, not an objective.
