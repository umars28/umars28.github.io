Infrastructure I build when nobody is paying me.

marstack-container

An OCI container runtime written from scratch. It explains container failures from kernel state instead of an exit code, and drops in as a Docker runtime.

Go→

marstack-cloud

A cloud platform for bare metal that treats container, VM, microVM and sandbox as one resource type, with native routing and no encapsulation in the data path.

QEMU · Cloud Hypervisor · Firecracker
Go→

marstack-secrets

A secret and parameter store that boots sealed. Envelope encryption bound to tenant, path and version, Shamir unsealing, default-deny policy, and an audit log it refuses to start without.

Sealed by default

marstack-access

Identity-aware access for Linux infrastructure. No standing credentials, certificates that never reach the user, tamper-evident audit, and sessions you can grep.

Agentless · short-lived certs
